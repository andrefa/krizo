# Krizo — MVP game design

## Fantasy
Krizo is an armadillo who got tired of digging down, built a questionable jetpack, and decided to find out how high he can go.

## Core loop
1. Start a run underground.
2. Hold boost and steer through a vertical route.
3. Collect coins and fuel.
4. Avoid rock formations and future hazards.
5. Eventually crash or fall below the camera.
6. Bank run coins.
7. Buy permanent garage upgrades.
8. Start again and reach a new layer.

## Permanent upgrades
- **Tank:** more total boost time.
- **Thrust:** stronger acceleration upward.
- **Control:** faster horizontal correction.
- **Efficiency:** lower fuel burn rate.

## Planned world layers
These are progression targets, not MVP requirements.

- 0–250 m: dirt / roots
- 250–600 m: cave / crystals
- 600–1000 m: sewer / foundations
- 1000–1600 m: city / buildings
- 1600–2400 m: clouds / aircraft junk
- 2400+ m: upper atmosphere / space nonsense

## MVP success criteria
The prototype is worth polishing when all three are true:

- restarting immediately feels tempting after a crash;
- controlling Krizo feels expressive rather than random;
- upgrades noticeably change the next run without trivializing it.

## Explicitly out of scope for first release
- accounts/backend
- multiplayer
- cloud save
- complex inventory
- story campaign
- procedural economy
- ads before the core loop is fun
